# SKA ACADEMY — Learn with Passion

Updated static website package for GitHub Pages with adaptive Desktop and Mobile layouts, full-screen syllabus dashboard, celebratory login banners, animated particles, home routing, and EmailJS registration.

## New Features & Responsive Layout Enhancements:
- **Responsive Layout Adaptation:**
  - **Desktop:** Expands into a wide, balanced multi-column grid view with optimal typography and header spacing.
  - **Mobile:** Re-aligns into stacked full-width touch-friendly buttons (`width: 100%`) with horizontal menu scrolling.
- **Home Navigation Option:** Clicking **Home 🏠** scrolls directly to the Registration section (`#enroll`).
- **Full Screen Syllabus View:** Expands into full viewport height (`min-height: calc(100vh - 120px)`) when logged in.
- **Celebratory Journey Banner:** Displays *"🎉 Congratulations! You Are In! Your learning journey has officially started."*
- **Go for Classes Action Buttons:** Direct shortcuts to jump straight to course selection.
- **Dark Ambient Background Animation:** Floating golden particles and pulsing radial backdrop glow.
