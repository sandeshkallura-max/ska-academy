# SKA ACADEMY — Learn with Passion

Updated static website package for GitHub Pages featuring custom **Logo Integration**.

## New Logo Integration (V9):
- **Logo Header:** Added `<img src="assets/logo.png" class="logo-img">` to the top navigation header next to "SKA ACADEMY" [cite: 8, 9].
- **Logo Footer:** Integrated the logo into the website footer [cite: 8, 9].
- **Automatic Fallback:** Includes an inline fallback (`⚙️`) if `assets/logo.png` is loading or missing.
- **Strict Login Credentials & Security:**
  - **Login ID:** Registered Phone Number or Email Address [cite: 10].
  - **Password:** Student's exact Full Name entered during registration [cite: 10].
  - Unregistered users are blocked and prompted to register first [cite: 10].

## How to Add Your Logo Image File:
1. Save your logo image file as `logo.png` inside the `assets/` folder of your project repo (`assets/logo.png`).
2. Upload the updated `index.html` file to your GitHub repository root.
